# oneyaml

**serde and lossless, comment-preserving editing for YAML 1.2, in one
crate.** Both run on one parser and one interpretation of the file, so a
typed read and an edit never disagree about what it means. Correct by
default, no `unsafe`, no panics on any input.

Instruction counts measure how much work each library does, exactly and
repeatably; they are not elapsed time. Wall-clock time agrees for serde
writes and for edits on documents above a few kilobytes, and is close to
parity for `Document` parsing (slightly slower on three of the five
workloads), but **serde reads are slower in wall-clock time on four of
the five workloads shown**, including three where oneyaml executes fewer
instructions; only on k8s-multi is oneyaml level. The tables above give the
absolute values, both ratios, every loss and the method; every workload
and how to reproduce them are in [docs/performance.md](docs/performance.md).

Correctness comes first: YAML 1.2.2 with the Core schema by default,
every YAML 1.1 behaviour an opt-in setting, checked against the full
yaml-test-suite ([conformance results](docs/conformance.md)), fuzzed
([crates/fuzz](crates/fuzz/README.md)) and tested against five other YAML
libraries ([correctness and safety](crates/oneyaml/README.md#correctness-and-safety)).

## Install

```sh
cargo add oneyaml serde -F serde/derive
```

## Quick start

Read and write typed data with serde, then edit a document in place:
the edit changes only what you touched, and the comment stays.

```rust
use oneyaml::Document;
use serde::{Deserialize, Serialize};

#[derive(Deserialize, Serialize)]
struct Config { name: String, port: u16 }

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // serde: read and write typed data.
    let cfg: Config = oneyaml::from_str("name: web\nport: 8080\n")?;
    assert_eq!(oneyaml::to_string(&cfg)?, "name: web\nport: 8080\n");

    // Read values from a document.
    let mut doc = Document::parse("server:\n  port: 8080  # public\ntags: [web]\n")?;
    assert_eq!(doc.get_path("server.port").and_then(|n| n.as_u64()), Some(8080));

    // Edit it: everything else, comments included, stays byte for byte.
    doc.set_path("server.port", 9090)?;
    doc.get_mut("tags")?.push("api")?;
    assert_eq!(doc.to_string(), "server:\n  port: 9090  # public\ntags: [web, api]\n");
    Ok(())
}
```

Errors come with a `Y####` code, a source snippet and a suggested fix;
see [diagnostics](crates/oneyaml/README.md#diagnostics). For input from
the network, use [`Limits::untrusted()`](crates/oneyaml/README.md#untrusted-input);
for docker-compose-style `<<` merge keys, turn on
[`merge_keys`](crates/oneyaml/README.md#merge-keys-).

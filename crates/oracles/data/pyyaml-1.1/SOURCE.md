# PyYAML 1.1 reference data

Recorded answers of a YAML 1.1 resolver, for `tests/compat_yaml11.rs`
(`Compat::yaml_1_1()` against a 1.1 reference).

- **Tool:** PyYAML 6.0.3 (`yaml.__with_libyaml__ == True`), `yaml.SafeLoader`
  (the pure-Python YAML 1.1 resolver and constructor), on CPython 3.13.
  PyYAML: <https://github.com/yaml/pyyaml>, tag `6.0.3`, MIT license.
- **Generated by:** `generate.py` in this directory (`python3 generate.py`),
  which writes both files. The inputs (the scalar list and the documents)
  are written for this corpus; only PyYAML's answers are recorded.
- **Files:**
  - `scalars.tsv` — `scalar \t type \t value`: the plain scalar, the type
    PyYAML resolved `k: <scalar>` to (`null`, `bool`, `int`, `float`,
    `timestamp`, `str`, or `error` when PyYAML refused the input), and the
    value (`~` for null, decimal for int, Python `repr` for float with
    `inf`/`-inf`/`nan`, ISO 8601 for timestamps).
  - `documents.tsv` — `name \t json(input) \t json(loaded)`: whole
    documents with merge keys (`<<`), loaded by PyYAML and dumped as JSON
    with sorted keys.

Regenerate only to add inputs; a changed answer for an existing input
means the reference changed and must be reviewed, not accepted.

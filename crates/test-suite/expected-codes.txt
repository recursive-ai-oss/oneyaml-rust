# Expected diagnostic codes per yaml-test-suite case.
#
# Format: <case-id> <Y####>...
#   The codes of every Error and Warning event the producer must emit for the
#   case, in stream order. Codes come from the registry in
#   crates/oneyaml-core/src/code.rs. A case without a line is not checked for
#   codes; a case id with no codes asserts that no diagnostics are emitted.
#   `ExpectedCodes::validate` checks every entry against the registry and the
#   vendored suite (run by the CLI and by tests/harness.rs).
#
# Syntax (Y0001-Y0999) codes are allocated by the parser work, and
# their entries are added together with the code that emits them (starting
# with the seven `+STR`-only error cases).

# The seven error cases whose recorded prefix is only `+STR`: the codes the
# parser (`--producer parser`) emits for them. These close the harness's
# "error then skip everything" loophole for those cases.

MUS6/01 Y0003   # %YAML inside a document not ended with `...`
SF5V Y0033      # second %YAML directive for one document
SY6V Y0006      # block sequence after properties on the same line
